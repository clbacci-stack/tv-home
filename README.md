# Claudio Home

A personal home screen for a Samsung Tizen TV, run through TizenBrew: clock, Luxembourg weather and app tiles.

- Install: TizenBrew → Module Manager → Add GitHub Module → `clbacci-stack/tv-home@v1.0.0`
- Settings: edit `config.js` (name, language, tile order, background photos, accent colour)
- YouTube opens through TizenTube. Apps not installed on the TV are hidden.
- Samsung's Home button still opens the Samsung menu.

Structure for the TizenBrew service and TizenTube launch adapted from Cinema Home (MIT) by Karmani-MR.
